## 1. 사용자가 직접 할 일
1. **Claude Code 재시작**
   - 새 `PLATFORM_MCP_TOKEN`은 유효하다(엔드포인트 200 확인).
   - 401이 난 이유: 실행 중인 프로세스가 env를 물려받지 못해 빈 Bearer로 붙었다.
   - 재시작한 뒤 이 문서와 47을 위키 '개발' 스페이스에 올린다.
2. **비밀번호 교체** — 런북 `infra/runbooks/secret-rotation.md`
   - 대상 일곱 키: DB·KC admin·KC 서비스 계정·MinIO·Grafana·OIDC·**Redis(§7, 새로 추가)**
   - 끝나면 `REQUIRE_STRONG_SECRETS=true`, `PLATFORM_DEFAULT_SECRETS_POLICY=enforce`로 잠근다.
   - Redis를 켜면 dev 오프셋 클러스터의 run 설정에도 비밀번호가 필요하다(§7).
3. **Keycloak 운영 모드**
   - `scripts/keycloak-harden.ps1`(계획 → `-Apply`). 기본 동작이 데모 계정 비번 무작위 교체라 alice 비번이 바뀐다.
   - `KC_HOST_BIND=127.0.0.1`
   - `start` 모드 전환
4. **전체 DB 정합 백업**
   - `backup-platform.ps1 -Quiesced`로 뜬다. 쓰기를 멈춰야 해서 수동이다.
   - 오프사이트 복원을 한 번 증명한 뒤 보존 기간을 정한다.
5. **브라우저 확인**

   - `SITE_URL`

## 4. 작업 규칙 (그대로)
- main에서 작업한다. main push는 곧 배포다.
- 파일을 지정해 스테이징하고, 커밋 전에 `git status -sb`를 본다.
  - **11-07~08에도 다른 세션이 wiki-front·alm-front를 동시에 수정했다.** 남의 미커밋 파일은 건드리지 않는다.
- 무거운 테스트·Codex·빌드와 배포를 겹치지 않는다.
- 커밋에 이슈 키를 단다(플랫폼 MCP를 되살린 뒤부터). 산출물 정본은 위키 '개발' 스페이스다.
- compose를 바꾸면 `scripts/tests/compose-hardening.test.ps1`를 꼭 돌린다.
  - 미설정 변수 경고가 smoke의 JSON 파싱을 깨는 것을 잡는다.
  - 이번에 중첩 보간 `${A:+${A}}`가 걸렸다. 기본값을 붙인 `${A:+${A:-}}`로 해결했다.
