## 1. 기능 — 위키에 새로 들어간 것

| 웨이브 | 기능 | 핵심 결정 |
|---|---|---|
| W23 | 리비전 편집자 이름 스냅샷(V28) | 디렉터리(ACTIVE만)→스냅샷→id 폴백 — 퇴사자가 고친 버전도 이름으로 |
| W23 | **알림 이메일 채널**(V29) + 설정 화면 `/settings/notifications` | OpenSearch처럼 **선택 옵션**(`WIKI_MAIL_HOST` 비면 알림함만). 주소는 토큰 email 클레임 스냅샷 — 발송 시점엔 수신자 토큰이 없다. 커밋 뒤 별도 스레드 발송 |
| W24 | **블로그** — `PageType.BLOG`, `/spaces/:id/blog` | 별도 엔티티 아님(본문·리비전·댓글·권한이 페이지와 같음). 트리 루트 쿼리에서 제외, 부모·이동 불가(400) |
| W23 | 스페이스 삭제 감사(V30) `/admin/audit` | audit_log의 space FK(cascade)를 **풀어** 기록이 스페이스보다 오래 살게. 전역 관리자만 |
| V31 | 이메일 **하루 요약(digest)** 모드 | `emailed_at` 마킹으로 "아직 안 나간 알림"을 모음 — 모드 바꿔도 재발송 없음. 7일 상한 |
| W23 | 속성 보고서 `::properties-report[라벨]` | 검색 색인이 아니라 **라벨 API + 본문**에서 읽음 → OpenSearch 유무 무관. 50건 상한 |
| W25 | **리비전 보관 정책**(사용자 결정) | 최근 100개 항상 + 90일 지난 것 정리. 현재 버전은 절대 안 지움. `WIKI_REVISION_PRUNE_ENABLED=false`로 무기한 복귀 |
| W26 | **PDF 내보내기**(사용자 요청 "md to pdf 오픈소스") | flexmark(MD→HTML) + jsoup(XHTML) + **openhtmltopdf 커뮤니티 포크 1.1.37**(순수 JVM, PDFBox 3) + NanumGothic 임베드. 브라우저 인쇄 결정을 뒤집음 — 테스트가 PDF에서 텍스트 추출해 한글 검증 |

설정 화면은 전부 **아이콘 · 제목 · 한 줄 설명** 구조로 통일(사용자 지시, 컨플루언스 실물 참조 —
`tom-chkim-dev.atlassian.net`을 브라우저로 캡처해 확인). `SettingsHeader`/`SettingsItem` 공통 컴포넌트.

## 3. 얻은 교훈 (다음에 또 만날 것)

- **pnpm 11은 리포에 커밋되는 프로젝트 `.npmrc`의 인증을 무시한다**(환경변수 참조여도). 해법: `~/.npmrc`에 `//npm.pkg.github.com/:_authToken=${GH_PACKAGES_TOKEN}` 한 줄(값 저장 안 함) + CI는 setup-node `registry-url`+`NODE_AUTH_TOKEN`.
- pnpm 오버라이드는 `pnpm-workspace.yaml`에 산다(10+) — package.json만 고치면 lockfile이 tgz를 계속 문다. `minimumReleaseAgeExclude`도 필요(방금 발행한 버전).
- GraphQL enum에 값이 빠지면 "표시가 다른" 게 아니라 **행 하나가 응답 전체를 깨뜨린다**(BLOG 사건).
- Boot 자동구성보다 **앞에** 서지 않는 커스텀 JwtDecoder 자동구성은 audience 검증을 조용히 잃는다 — `@AutoConfiguration(beforeName=…)` + 팩토리 빈 검증 테스트.
- 메일은 커밋 뒤·별도 스레드: 저장이 SMTP에 묶이거나 롤백된 저장의 메일이 나가면 안 된다.
- CI 간헐 실패 대부분은 테스트의 동기 `getByRole` — `findBy*`/`waitFor`로.
- 잘린 CI displayTitle에 정규식 매칭하면 감시 루프가 헛돈다 — 짧은 접두로 매칭.
